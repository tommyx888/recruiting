🔧 SendGrid Quick Fix

Problém: Edge Function používa placeholder API Key

Riešenie: Zadajte vaše SendGrid údaje a ja ich aktualizujem

Nájdete ho v SendGrid Dashboard > Settings > API Keys
Musí byť overená v SendGrid (Single Sender Verification)

📋 Čo sa stane:

  1. Vygenerujem kód na aktualizáciu Edge Function
  2. Skopírujete kód a nahradíte ho v Edge Function
  3. Redeploy Edge Function
  4. Test s novými údajmi

🔍 Ako nájsť SendGrid údaje:

API Key:

  1. Prihláste sa do SendGrid Dashboard
  2. Choďte do Settings > API Keys
  3. Kliknite na váš API Key alebo vytvorte nový
  4. Skopírujte kľúč (začína sa s "SG.")

From Email:

  1. Choďte do Settings > Sender Authentication
  2. Nájdite "Single Sender Verification"
  3. Použite overenú email adresu
